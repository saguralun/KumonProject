## ขอบเขตความเข้ากันได้

- ไม่เพิ่ม/ลบตาราง คอลัมน์ หรือเปลี่ยนสูตรค่าเรียน จำนวนคลัง และสูตร Forecast
- ป้องกัน stale quantity ด้วยจำนวนเดิมภายใต้ lock ของ DO ไม่อ้างว่าเป็น version
  ของทุก field; การเปลี่ยนจำนวนแล้วกลับเป็นจำนวนเดิมไม่ถือว่าเป็นยอดที่ต่างกัน
- จำนวนเดิมจากข้อมูลเก่าเป็น 0 หรือติดลบยังนำมาใช้ตรวจ snapshot เพื่อแก้ให้ถูกได้
  จำนวนใหม่ยังต้องเป็นจำนวนเต็มมากกว่า 0 ไม่ปรับยอดเก่าให้อัตโนมัติ
- API แก้จำนวนจากหน้ารุ่นเก่าที่ไม่ส่งจำนวนเดิมจะให้โหลดหน้าใหม่ก่อน ไม่เขียนทับเงียบ ๆ
  ผู้เรียก service ภายในแบบเดิมยังใช้ได้; UI ปัจจุบันส่งจำนวนเดิมเสมอ
- Draft Students อยู่เฉพาะฟอร์มในหน้าที่เปิด ไม่ใช่การ autosave และไม่เก็บชื่อเด็กลง
  localStorage การปิด/โหลดทั้งหน้าใหม่ยังเป็นขอบเขตการสูญเสียค่าที่ยังไม่บันทึก
- ผล Report B/CSV และรหัสคอลัมน์ข้อมูลหลักไม่เปลี่ยน; Excel สรุปเลเวลเปลี่ยนชื่อ
  คอลัมน์หน่วยจาก “นักเรียน (คน)” เป็น “จำนวนรายวิชา” โดยลำดับ/จำนวนคอลัมน์และตัวเลขเดิม
- Forecast ไม่เดาค่าเฉลี่ยที่ไม่มีให้เอง และไม่แปลงยอดขาดเป็น 0
- AT/KSIS ตรวจและแก้ใน fixtures เท่านั้น ไม่มีการเข้าบัญชีจริงหรือบันทึกข้อมูลจริง
  อ่านค่าบนหน้าที่ไม่ได้ refresh จะไม่อ้างว่าเป็นผลที่บันทึกแล้ว
- N/EO/IT ที่จับคู่ด้วยชื่อ/วันเกิดยังใช้ Enrollment ID เลือกแถว Report ตอนตรวจ
  แม้มีรหัสชั่วคราวเป็นตัวเลขแล้ว จึงไม่กลับไปบังคับรหัสคุมองในเส้นทางตรวจ
- เก็บพฤติกรรมเดิมของ Half Month, สถานะ, การเลื่อนระดับ และสิทธิ์เดิมไว้

## ทดสอบ

- มีรอบก่อนแก้ที่ล้มเหลวตามปัญหาข้างต้น และรอบหลังแก้แยกกันใน `logs/round2-*`
  ความล้มเหลวแรกของ Student fixture เพราะไม่ได้เปิดรายละเอียด ถูกแก้ให้คลิก
  เปิดตามจริงก่อนจำลอง จึงได้ assertion ค่าหายจริงก่อนแก้ production code
- คลังทดสอบ retry, append, edit, Process, rollback และ guarded edit กับ PostgreSQL
  ชั่วคราวที่ตรวจ identity ก่อน redirect ทั้ง pool.query/connect
- Students ทดสอบข้ามฟอร์มทั้งชื่อ, หมายเหตุ, เลเวล, ชุดเริ่ม, วันที่, Half Month
  และ KC พร้อมยกเลิกการทิ้ง draft และตรวจว่าไม่ส่งคำขอบันทึกเพิ่ม
- รายงานทดสอบข้อมูลขาดและข้อมูลครบ การคำนวณใหม่ หน่วยใน tooltip และไฟล์ส่งออกปกติ
- AT ทดสอบปุ่มจริง, การยกเลิก, ประวัติเดิม, ไม่เลื่อนซ้ำ, no-ID selector, DOM KSIS
  จำลอง, การไม่ทิ้ง dirty inputs, pending guards และ workspace ที่เปิดหลายหน้าต่าง
