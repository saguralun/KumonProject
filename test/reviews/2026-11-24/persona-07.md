**1) บุคลิกและงานเป้าหมาย**

เจ้าของศูนย์ที่ต้องใช้เวลาสั้น ๆ ตอบให้ได้ว่า งวดนี้มีเด็กเท่าไร ต่างจากงวดก่อนอย่างไร เด็กก้าวหน้าหรือมีข้อมูลตกหล่น และควรเตรียม/ซื้อแบบฝึกหัดเท่าไร ต้องการตัวเลขที่อธิบายฐานนับได้และส่งออกไปตรวจย้อนหลังได้ โดยไม่ต้องรู้โครงสร้างฐานข้อมูล

ขอบเขตนี้ตรวจความหมายและความน่าเชื่อถือของรายงาน ไม่ประเมินขั้นตอนรับเงิน ตัดสต็อก หรือส่งข้อมูล KSIS ของบทบาทอื่น

**3. P2 — Progress ไม่แยก “ยังประเมินไม่ได้” ออกจาก “ยังไม่ทันชั้นเรียน”**

- **สถานการณ์:** enrollment active มีเลเวลที่รองรับ แต่ไม่ได้ระบุชั้นเรียน เปิด Progress โดยเลือกทั้งหมด
- **ยืนยันจากโค้ด:** service ส่งเด็กกลับมาพร้อม `gradeClass=null`; ตัวคำนวณคืน `null` เมื่อไม่มีชั้นเรียน ฝั่ง UI ใช้สถานะ `none` แทนค่า null และนำไปรวมยอด active แต่ไม่รวมยอดทันชั้นเรียน อีกทั้งไม่มีคอลัมน์ชั้นเรียนสำหรับวาดจุดของเด็กคนนี้
- **ผลกระทบ/วิจารณ์ UX:** เด็กที่ประเมินไม่ได้เพิ่มช่องว่างระหว่าง “ทั้งหมด” กับ “ทันชั้นเรียนขึ้นไป” และไม่มีจุดให้ตรวจต่อ เจ้าของอาจตีความเป็นเด็กตามไม่ทัน ทั้งที่ปัญหาคือข้อมูลไม่ครบ
- **แนวปรับเล็กและชัด:** เพิ่มสถานะ “ข้อมูลไม่พอประเมิน” แยกจาก `none` พร้อมจำนวนและรายชื่อ ไม่รวมกลุ่มนี้ในการสรุปผลสัมฤทธิ์ และแสดงจำนวนเด็กที่วาดในกราฟเทียบกับจำนวน active

**5) ข้อจำกัดและกรณีที่ควรทดสอบเพิ่มเติม**

ข้อค้นพบข้างต้นยืนยันเส้นทางและเงื่อนไขจากโค้ด แต่ยังไม่ยืนยันความถี่ในข้อมูลจริงหรือผลที่ผู้ใช้รับรู้จากหน้าจอ Test ที่อ่านเป็นหลักฐานว่าโครงการตั้งใจตรวจอะไร **ไม่ได้หมายความว่ารอบนี้รันผ่าน** รวมถึงผลในเอกสาร cleanup เป็นผลที่เอกสารบันทึกไว้ ไม่ใช่ผลทดสอบใหม่ของการรีวิวนี้

กรณีที่ควรให้ parent ตรวจด้วย synthetic fixture:

- Forecast ที่ขาด average ตั้งแต่ packet แรก และขาดกลางเส้นทาง ตรวจยอดบางส่วน ข้อความเตือน และไฟล์ส่งออก
- เด็กคนเดิมเปลี่ยนสถานะ/เลเวลหลังงวดอ้างอิง ตรวจว่ารายงานรายเดือนกับสรุปเลเวลสื่อฐานเวลาต่างกันชัดหรือไม่
- Progress ที่ไม่มีชั้นเรียน ไม่มี WS แบบ `cpws=true` หรือมีเลเวลนอก mapping ตรวจจำนวนในการ์ดเทียบกับจำนวนจุด
- เด็กหนึ่งคนหลายวิชา และหลายเหตุการณ์ในงวด ตรวจหน่วย Statistics เทียบ Report โดยไม่สมมติว่าทุกยอดคือคนไม่ซ้ำ
- วันที่ 20/21 และ 20/21 ธันวาคมข้ามปี พร้อมการกรอก 2026/2569 ตรวจงวดเริ่มต้น ค.ศ./พ.ศ. และวันที่ใน CSV/Excel
