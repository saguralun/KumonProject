## การทดสอบบน Windows

เพิ่มเวลารอเริ่มโปรเซสสำรองข้อมูลจำลองจาก 15 เป็น 45 วินาที และเผื่อเวลาเริ่ม
PostgreSQL cluster ชั่วคราว โดยใช้ `initdb --no-sync` คู่กับ `-F` ที่ fixture
ใช้อยู่แล้ว เงื่อนไขตรวจธุรกรรมและความถูกต้องของข้อมูลยังเหมือนเดิม
การเก็บ fixture รายงาน cleanup error โดยไม่กลบสาเหตุแรก และไม่ลบข้อมูลของ
cluster หากยังยืนยันการหยุดไม่ได้

การตรวจ UI ซ้ำใช้เวลารอของ test เพิ่ม 3 เท่า โดยไม่แก้ assertion หรือข้อมูล
fixture ส่วนชุดทดสอบ UI ปกติยังใช้เวลารอเดิม รอบ opt-in ทั้งโปรเจกต์ครั้งแรก
ถูกหยุดเพราะหลายกรณีหมดเวลา จึงไม่รายงานว่าการรันรวมครั้งเดียวนั้นผ่านทั้งหมด
ทั้ง 21 กรณีที่รายงานล้มเหลวก่อนหยุดรอบนั้น ได้พบผลผ่านในการตรวจซ้ำแยกแล้ว

ผลทั้งหมดใช้ test doubles, เว็บจำลอง, profile Electron ชั่วคราว หรือ PostgreSQL
cluster ที่ตรวจยืนยันตำแหน่งและพอร์ตของตัวเองแล้ว ไม่รับเงินจริง ไม่พิมพ์จริง
ไม่กรอก/บันทึก KSIS จริง และไม่ปรับข้อมูลหรือ schema ของเครื่องใช้งาน
